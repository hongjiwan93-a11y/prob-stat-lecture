# 교육스킬test: 차시별 강의 슬라이드 제작

인자: 차시 번호 (`$ARGUMENTS`). 없으면 `03_초안/`에 아직 없는 가장 앞 차시를 골라 진행하고 어떤 차시인지 한 줄로 알림.

## 1. 기준 파일 읽기 (한 번에 병렬로)
- `CLAUDE.md`: 대상, 말투, 그림 원칙, 차시 구성 템플릿
- `00_기획/커리큘럼.md`: 해당 차시의 주제, 교과서 개념, 교과서 쪽, PDF 쪽
- `02_스타일/디자인규칙.md`, `02_스타일/예시자료/` (있으면)
- 앞 차시 결과물 `03_초안/(N-1)차시/project/slides/`: 지난 시간 요약과 디자인 일관성 확인용

## 2. 교과서 범위 읽기
- 쪽 변환: **PDF 쪽 = 교과서 쪽 − 77**
- `01_참고자료/교과서/페이지이미지/p-NN.png`를 해당 범위 전부 Read로 확인 (수식, 그래프, 표는 이미지 기준)
- `3단원_텍스트.txt`는 본문 검색용. 수식과 개념 제목은 글자가 깨져 있으므로 그대로 옮기지 말 것
- 교과서의 개념 번호, 제목, 탐구·예제·문제 번호와 쪽을 메모: 슬라이드 eyebrow와 노트에 출처로 표기

## 3. 구성 (약 22~26장)
1. 표지 (남색 배경, 차시·제목·교과서 쪽)
2. 지난 시간 요약 (1차시는 단원 지도로 대체)
3. 오늘의 질문: 공학 상황 하나 (남색 배경 statement)
4. 학습목표 3개: 카드마다 작은 그림
5. 본문: 개념마다 직관(탐구/생각 열기) → 정의 박스 → 예제(문제·풀이 분리) → 공학 응용
6. 확인 문제 3개 + 풀이 (교과서 문제를 공학 상황으로 바꿔도 됨, 바꾼 사실은 노트에 기록)
7. 요약: 그림 중심 1장
8. 다음 시간 예고 (남색 배경, 다음 차시 교과서 쪽)

- 교과서 범위 밖 내용은 eyebrow나 푸터에 "보충" 표시
- 수치는 반드시 직접 계산해 검증. 확률표는 합계 1 확인

## 4. 말투: 명사형 종결
- 슬라이드 글, 제목, 발표자 노트(`<aside>`) 모두 명사 또는 ~함/~임/~됨으로 종결
- ✅ "확률 = 곡선 아래 넓이", "독립이면 곱셈 성립" / ❌ "~입니다", "~한다"
- 질문형 도입은 허용

## 5. 제작: Slides 아티팩트
1. `Artifact` `action: "quickstart"`, `intent: "slides"` → 안내된 Slides type_url로 새 아티팩트 생성 (`title`: "N차시 주제", `auto_open: "after_first_write"`)
2. 생성 결과의 type 지침을 그대로 따름. 파일 위치: root = `03_초안/NN차시` (예: `03_초안/02차시`), 그 아래 `project/deck.json`, `project/slides/<id>.html`
3. deck.json(전체 order, sections, faces) + 표지 먼저 발행, 이후 3장씩 Write 후 한 번에 발행
4. 렌더링 확인용 재읽기, 스크린샷은 하지 않음

### 디자인 토큰 (1차시와 동일하게 유지)
- 배경: 기본 `#F7F5EF`, 예제·비교 `#EDF1F6`, 표지·질문·예고 `#1F2A44`
- 글자: 제목 `#1F2A44`, 본문 보조 `#4A5568`, 푸터 `#6B7280`
- 파랑(기본·이산) `#2F6DB5` / 연파랑 `#DCE7F5`
- 주황(강조·확률·연속) `#D9661F` / 연주황 `#FBE3D2` / 주황 글자 `#B4531A` / 어두운 배경 위 주황 `#F2A66B`
- 카드 `#FDFCF9` + `border:2px solid #C9D3E3`
- 글꼴 faces: `IBM Plex Sans KR`(제목, 500;700), `Noto Sans KR`(본문, 400..800)
- 크기: 제목 64px(표지 96, statement 72), 강조 40~44, 본문 30~32, 라벨·푸터 24

### 반복 마크업
- section: `padding:128px 128px 160px; display:flex; flex-direction:column; gap:40~48px`
- 머리: eyebrow `<p>` 24px bold `#B4531A` ("개념 2 · 이산확률변수") + `<h2>` 64px
- 푸터: 왼쪽 `<p>` pinned `left:128px;bottom:64px;width:1200px` ("N차시 주제 · 교과서 NN쪽"), 오른쪽 쪽번호 `<p>` pinned `right:128px;bottom:64px;width:200px;text-align:right`
- 정의 박스: 연파랑(또는 연주황) 배경 + `border-left:10px solid` 진한 색
- 참고 예시: `03_초안/01차시/project/slides/*.html`

### 그림 (SVG)
- 슬라이드마다 그림 최소 1개, `width`/`height` = `viewBox`
- 곡선 아래 넓이: 닫힌 path + `clipPath` rect로 구간만 주황 채움
- 이산 분포: 굵은 stroke 막대(`stroke-linecap:round`) + 끝 점
- 축 라벨, 수치는 `<text font-family="sans-serif">`, 변수는 `font-style="italic"`
- 적분 기호처럼 위아래 첨자가 필요한 수식은 SVG `<text>`로 위치 지정 (`<sub>`/`<sup>` 사용 불가)
- 같은 개념은 같은 색 유지 (이산 = 파랑, 연속·강조 = 주황)

### 세로 공간 점검
- 내용 영역 높이 약 792px (1080 − 128 − 160)
- 머리 ≈ 106px, 한글 글자 폭 ≈ font-size × 1.0, 줄 높이 ≈ font-size × 1.4~1.5
- 넘칠 것 같으면 줄이지 말고 문장을 노트로 옮기거나 슬라이드 분리

## 6. 마무리
- `python3 tools/build_site.py`로 웹 슬라이드 갱신, 필요하면 `docs/NN/quiz.html`, `docs/NN/playground.html`도 `docs/01/`을 본떠 작성
- `CLAUDE.md`의 「차시별 아티팩트 링크」에 `- N차시: <url> (로컬: 03_초안/NN차시/)` 추가
- 사용자에게: 링크, 구성 표(슬라이드 번호별 내용), 교과서에서 바꾼 부분과 보충 내용, 비공개 상태라 공유 메뉴에서 공유해야 다른 사람이 볼 수 있다는 점 안내
