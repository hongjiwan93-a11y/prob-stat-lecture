P(X = x)

확률변수 X가 값 x를 취할 확률

이산확률변수 정의. 핵심은 "셀 수 있음". 값이 무한히 많아도 0, 1, 2, …처럼 하나씩 셀 수 있으면 이산. 각 값마다 확률이 하나씩 붙는 구조이므로 그림처럼 점마다 질문표. 이 확률들을 모두 모아 놓은 것이 다음 장의 확률분포.

확률분포: 값과 확률의 짝

확률질량함수

P(X = xᵢ) = pᵢ

(i = 1, 2, 3, …, n)

예: 동전 2회, X = 앞면의 횟수

X012합계

1차시 확률변수와 확률분포 · 교과서 82쪽

09

확률분포: X가 취하는 값 x₁, x₂, …, xₙ과 각 값의 확률 p₁, p₂, …, pₙ 사이의 대응 관계. 이를 함수로 쓴 것이 확률질량함수. 표 하나, 그래프 하나로 같은 정보 표현. 그래프에서 막대의 길이가 곧 확률. 동전 예시에서 앞면 1번이 가장 높은 이유: (H, T), (T, H) 두 근원사건이 모두 1로 대응하기 때문.

개념 2 · 이산확률변수

확률질량함수의 두 성질

성질 1

0 ≤ pᵢ ≤ 1

각 확률은 0 이상 1 이하

성질 2

p₁ + p₂ + … + pₙ = 1

모든 확률의 합은 1

참고 · P(a ≤ X ≤ b): X가 a 이상 b 이하의 값을 가질 확률

1차시 확률변수와 확률분포 · 교과서 82쪽

10

확률질량함수의 두 성질. 성질 2는 "가능한 경우를 빠짐없이, 겹치지 않게 모두 모으면 확률 1"이라는 뜻. 막대 그림처럼 길이 1인 띠를 값별로 나눠 가지는 모습으로 설명. 문제에서 미지의 상수가 나오면 거의 항상 성질 2를 이용해 결정. 이 성질은 연속확률변수에서 "전체 넓이 = 1"로 그대로 이어짐.

개념 3 · 연속확률변수

연속확률변수: 확률은 넓이

연속확률변수: 어떤 범위에 속하는 모든 실수의 값을 취하는 확률변수

대기 시간 X의 확률

P(a ≤ X ≤ b) = (b − a)/10

= 색칠한 직사각형의 넓이

전체 넓이: 10 × 1/10 = 1

1차시 확률변수와 확률분포 · 교과서 84쪽

14

대기 시간은 0에서 10 사이 모든 실수이므로 연속확률변수. 대기 시간이 a분 이상 b분 이하일 확률은 구간 길이에 비례하여 (b − a)/10. 이 값을 높이 1/10인 직사각형의 넓이로 해석하는 것이 핵심 전환. 함수 f(x) = 1/10이 이 확률분포를 나타내는 확률밀도함수. 전체 넓이가 1이라는 점은 이산에서 확률의 합이 1이었던 것과 같은 역할.

1차시 확률변수와 확률분포

15

오늘 수업에서 가장 중요한 비교. 이산확률변수는 값 하나하나에 확률이 붙고, 그 확률이 막대의 길이. 연속확률변수는 값 하나에 확률을 줄 수 없고, 구간에 대해서만 확률을 말하며, 그 확률이 곡선 아래 넓이. 곡선의 높이 f(x)는 확률이 아니라 "확률의 밀도"라는 점 강조. 그래서 f(x)가 1보다 큰 것도 가능.

개념 3 · 연속확률변수

확률밀도함수의 세 성질

X: α ≤ X ≤ β의 모든 실수 값을 취하는 연속확률변수, y = f(x): 확률밀도함수

1 f(x) ≥ 0

2 그래프와 x축, x = α, x = β로 둘러싸인 넓이 = 1

3 P(a ≤ X ≤ b) = 그래프와 x축, x = a, x = b로 둘러싸인 넓이

1차시 확률변수와 확률분포 · 교과서 84~85쪽

16

교과서 85쪽 성질 정리. 성질 1과 2는 이산확률변수의 두 성질과 짝: 확률은 음수가 아님, 전체 합은 1. 성질 3은 확률을 계산하는 방법. 이때 X는 확률밀도함수가 y = f(x)인 확률분포를 따른다고 표현. 교과서 보기: P(200 ≤ X ≤ 250)은 200과 250 사이 색칠한 부분의 넓이.

개념 3 · 생각과 표현

한 점의 확률은 0

선분의 넓이 = 0 → P(X = b) = 0

지하철 질문 3의 답: 정확히 5분 기다릴 확률 0

따라서 등호 유무와 상관없이 같은 확률

P(a ≤ X ≤ b) = P(a < X ≤ b) = P(a ≤ X < b) = P(a < X < b)

1차시 확률변수와 확률분포 · 교과서 85쪽

17

교과서 85쪽 생각과 표현. 넓이를 두 조각으로 나누면 오른쪽 끝 선분 하나가 남음. 선분은 폭이 0이므로 넓이 0. 따라서 연속확률변수에서 특정한 한 값을 취할 확률은 항상 0. 확률 0이 "절대 일어나지 않음"을 뜻하지는 않는다는 점도 짚기: 실제로 누군가는 어떤 정확한 시간만큼 기다림. 공학적 의미: 측정값이 정확히 5.000…V일 확률은 0, 그래서 항상 허용 오차 구간으로 품질 기준을 정함.

예 · 교과서 85쪽 문제 3

삼각형 넓이로 구하는 확률

0 ≤ X ≤ 4, 확률밀도함수 f(x) = kx일 때 상수 k와 P(0 ≤ X ≤ 2)

전체 넓이 = 1

1/2 × 4 × 4k = 8k = 1

→ k = 1/8

주황 삼각형의 넓이

1/2 × 2 × f(2) = 1/2 × 2 × 1/4

→ P(0 ≤ X ≤ 2) = 1/4

1차시 확률변수와 확률분포

18

교과서 85쪽 문제 3. 미지의 상수는 "전체 넓이 = 1" 조건으로 결정. 넓이는 삼각형 공식만으로 충분. 관찰 포인트: 구간 [0, 2]는 전체 구간의 절반이지만 확률은 1/4. f(x)가 오른쪽으로 갈수록 커져서 큰 값이 더 잘 나오는 분포이기 때문. 이산의 "막대가 긴 값이 잘 나옴"과 같은 직관.

개념 4 · 심화 · 미적분 연결

넓이 = 정적분

성질 1
