확률분포 플레이그라운드

1차시 확률변수와 확률분포 · Manim 스타일 애니메이션 (브라우저에서 바로 실행)

  • 파란 막대: 이론 확률 P(X = k)
  • 주황 테두리 막대: 실제로 뽑은 표본에서 불량품 k개가 나온 비율
  • 표본이 많아질수록 주황 막대가 파란 막대에 가까워짐 → 3차시 큰수의 법칙 예고

  • 그래프 위 a, b 핸들을 끌어서 구간 조절 가능
  • 확률 = 곡선 아래 넓이 = 정적분
  • 리만 합 직사각형을 늘릴수록 정적분 값에 가까워짐
  • 4x³ 선택 시 높이가 1보다 큰 부분 확인: 밀도는 확률이 아님

  • 구간 폭이 0에 가까워지면 넓이도 0으로 수렴
  • 높이 f(c)는 그대로여도 한 점의 확률은 0
  • 그래서 P(a ≤ X ≤ b) = P(a < X < b)
