이산확률변수

값 · 셀 수 있는 값

함수 · 확률질량함수 P(X = xᵢ) = pᵢ

확률 · 막대의 길이

성질 · 0 ≤ pᵢ ≤ 1, 확률의 합 = 1

연속확률변수

값 · 구간의 모든 실수

함수 · 확률밀도함수 f(x)

확률 · 곡선 아래 넓이 = 정적분

성질 · f(x) ≥ 0, 전체 넓이 = 1, 한 점의 확률 = 0

24

오늘 내용 요약. 확률변수는 근원사건을 실수로 바꾸는 규칙. 값을 셀 수 있으면 이산, 구간 전체면 연속. 이산은 막대의 길이, 연속은 넓이로 확률을 읽음. 두 경우 모두 "음수 아님, 전체 = 1"이라는 같은 구조. 이 그림 두 장만 기억해도 오늘 수업의 핵심 확보.
