개념 1 · 확률변수

동전 두 번: 결과를 숫자로

탐구 · 교과서 81쪽

H: 앞면, T: 뒷면

X = 앞면이 나온 횟수

근원사건 4개 → 값 3개

(H, T)와 (T, H)는 같은 값 1로 대응

1차시 확률변수와 확률분포

05

교과서 81쪽 탐구하기. 동전 두 번 던지기의 표본공간은 근원사건 4개. 각 근원사건에 앞면의 횟수라는 숫자를 붙이면 2, 1, 1, 0. 이 대응 규칙 자체가 확률변수 X. 서로 다른 근원사건이 같은 값으로 가는 것은 허용, 하나의 근원사건이 두 값으로 가는 것은 불가. 즉 함수와 같은 구조임을 강조.
