정적분으로 구하는 확률

0 ≤ X ≤ 1, 확률밀도함수 f(x) = ax³일 때 ⑴ 상수 a ⑵ P(0 ≤ X ≤ 1/2)

⑴ 전체 넓이 = 1

⑵ 0부터 1/2까지의 넓이

1차시 확률변수와 확률분포

20

교과서 86쪽 예제 2. ⑴ 전체 적분값이 1이라는 조건에서 a = 4. ⑵ 4x³의 부정적분은 x⁴이므로 (1/2)⁴ = 1/16. 그래프로 확인하면 구간 길이는 절반인데 넓이는 겨우 6.25%. 곡선이 오른쪽에서 급격히 높아지기 때문. 앞의 삼각형 예와 같은 직관을 정적분으로 정밀하게 확인한 것. 교과서 문제 4는 과제로 제시.
